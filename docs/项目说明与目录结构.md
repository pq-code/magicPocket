# MagicPocket 项目说明与目录结构

## 一、项目简述

**MagicPocket** 是一款基于 **Electron + Vue 3 + TypeScript** 的桌面应用，核心是**低代码搭建平台**：通过拖拽组件、配置属性、生成 JSON 描述，快速搭建页面（表单、表格、容器等），并支持「假代码」转真实函数、代码生成、配置持久化。同时内置**全局悬浮对话**（可拖动圆 + 聊天窗口 + Agent 设置弹窗），为后续接入 AI 对话与 Agent 预留入口。

- **定位**：桌面端低代码编辑器 + 对话/Agent 能力入口  
- **技术栈**：Electron、Vue 3、Pinia、Vue Router、Element Plus、Vue JSX、Less、electron-vite  
- **运行方式**：主进程创建窗口并启动 Express + Socket.IO；渲染进程为 Vue SPA，默认进入低代码画布页  

目前分为3大类，组件库，渲染器，控制器。左中右排列。
- 组件库：组件库，用于展示组件，支持拖拽组件，支持配置属性，支持生成 JSON 描述
- 渲染器：低代码画布、拖拽组件、属性面板、代码编辑器、版本控制、全局悬浮对话
- 控制器：用户相关接口逻辑（如 Koa Router 用），按模块分子目录

## 三、目录结构总览

```
magicPocket/
├── build/                 # 构建资源（图标、entitlements 等）
├── resources/             # 应用图标等静态资源
├── src/
│   ├── main/              # Electron 主进程
│   ├── preload/           # 预加载脚本（可承载 Node/Express/DB/WS）
│   └── renderer/          # 渲染进程（Vue 应用）
├── docs/                  # 项目文档
├── ui/                    # 设计稿（如 .pen）
├── package.json、electron.vite.config.ts、tsconfig.* 等
└── README.md
```

## 四、目录分类说明

### 4.1 根目录

| 路径 | 分类 | 说明 |
|------|------|------|
| `build/` | 构建资源 | 打包用图标（icns/ico/png）、mac entitlements 等 |
| `resources/` | 静态资源 | 应用图标等 |
| `docs/` | 文档 | 项目说明、架构、DDD 等文档 |
| `ui/` | 设计 | 设计稿文件（如 Pencil .pen） |
| `src/` | 源码 | 主进程、预加载、渲染进程 |

---

### 4.2 主进程 `src/main/`

| 文件/目录 | 说明 |
|-----------|------|
| `index.ts` | 创建 BrowserWindow、注册菜单、加载渲染页；应用就绪后调用 `linkStartHttp()` 启动 Express + Socket.IO |

---

### 4.3 预加载层 `src/preload/`

预加载脚本运行在「主进程与渲染进程之间」，可访问 Node、启动 HTTP/WS 等。当前结构按**功能域**划分：

| 路径 | 分类 | 说明 |
|------|------|------|
| `index.ts` | 入口 | 向渲染进程暴露 `electron`、`api` 等 |
| `app/` | 应用启动 | `index.ts` 内启动 Express + Socket.IO，提供静态与 WS |
| `config/` | 配置 | 日志配置、Node 端配置（如端口） |
| `constants/` | 常量 | 错误类型等 |
| `controller/` | 控制器 | 用户相关接口逻辑（如 Koa Router 用） |
| `service/` | 服务层 | 用户业务服务 |
| `model/` | 数据模型 | Sequelize 模型：用户、低代码配置（lowCodeConfig） |
| `db/` | 数据库 | SQLite/Sequelize 连接 |
| `router/` | 路由 | Koa 路由（如 user、lowCode），按模块分子目录 |
| `socket/` | 通信 | HTTP、TCP、WebRTC、WS 等实现（部分已停用） |
| `utils/` | 工具 | 通用工具、服务辅助函数 |

---

### 4.4 渲染进程 `src/renderer/`

#### 4.4.1 入口与壳

| 路径 | 分类 | 说明 |
|------|------|------|
| `index.html` | 入口 HTML | 挂载 Vue 应用的根节点 |
| `src/main.ts` | 渲染入口 | 创建 Vue 应用、注册 Router/Pinia/Element Plus/iconfont/高亮等 |
| `src/App.vue` | 根组件 | `<router-view />` + 全局悬浮对话组件 |
| `src/env.d.ts` | 类型 | 渲染进程环境/全局类型声明 |

#### 4.4.2 路由 `src/renderer/src/router/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `index.ts` | 路由定义 | 创建 Vue Router；首页重定向到低代码页；dashboard 与低代码页路由 |
| `branch/` | 路由分支 | 按功能拆分的路由配置（如 `draggingDragging.ts`） |

#### 4.4.3 状态 `src/renderer/src/stores/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `index.ts` | Store 入口 | 创建 Pinia 并导出 |
| `draggingDragging/` | 低代码状态 | 画布 pageJSON、当前操作节点、历史等 |
| `useMainStore.ts` | 全局状态 | 通用全局状态（若需） |

#### 4.4.4 接口与请求 `src/renderer/src/api/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `index.ts` | 请求封装 | Axios 实例、拦截器（Token、错误、登出） |
| `apis/` | 接口按域 | `user.ts`、`lowCode/lowCode.ts` 等 |
| `error/` | 错误处理 | 错误码与提示文案 |
| `types/` | 类型 | 请求/响应相关 TS 类型 |

#### 4.4.5 视图 `src/renderer/src/views/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `dashboard/` | 仪表盘 | 带侧栏的布局壳，子路由为低代码等 |
| `draggingDragging/` | 低代码页 | 三栏：左侧组件库、中间画布、右侧属性面板；内含 hooks、样式、类型 |

视图按**页面/功能模块**划分，每个 view 下可有 `components/`、`hooks/`、`style/`、`type/` 等。

#### 4.4.6 组件 `src/renderer/src/components/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `FloatingChat/` | 全局能力 | 悬浮对话：可拖动的圆、聊天窗口、设置/关闭、Agent 设置弹窗（左右布局） |
| `materialArea/` | 低代码物料 | 组件库定义与列表（Container、Form、Table、Input、Select 等） |
| `QuillCodeEditor/` | 编辑器 | 富文本/代码片段编辑 |
| `Versions.vue` | 业务组件 | 版本等相关 UI |

此处为**跨页面复用**或**全局级**组件；页面专属组件放在对应 `views/xxx/components/`。

#### 4.4.7 低代码引擎包 `src/renderer/src/packages/`

与低代码编排、渲染、配置强相关的「包」，统一放在 `packages/` 下，便于与业务视图解耦：

| 路径 | 分类 | 说明 |
|------|------|------|
| `RenderEngine/` | 渲染引擎 | 根据 pageJSON 树递归渲染；TypeRenderEngine 按类型映射组件；ComponentMaker 包裹可操作节点（选中、删除、拖拽） |
| `ControlPanel/` | 控制面板 | 根据选中节点 props 动态渲染配置项（PropsItem、异步加载自定义面板） |
| `DlockContainer/` | 容器组件 | 可嵌套拖拽的容器 + 操作面板 |
| `Form/` | 表单包 | 表单编排、表单项配置、FormOperatorPanel、假代码事件绑定 |
| `Table/` | 表格包 | 表格组件、列配置、TableColumnConfig 等 |
| `Input/` | 输入组件 | 输入类组件 |
| `PageContainer/` | 页面容器 | 页面级容器与工具 |
| `CreateCode/` | 代码生成 | 根据当前配置生成 Vue/JSX 代码片段 |
| `CodeHighlight/` | 代码高亮 | 高亮展示 |
| `index.ts` | 包入口 | 对外注册/导出可在其他页面复用的包（如 Form） |

#### 4.4.8 资源与样式 `src/renderer/src/assets/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `css/` | 全局样式 | 如 `styles.less` |
| `iconfont/` | 图标字体 | iconfont 相关 css/js/字体文件、demo |

#### 4.4.9 工具与类型 `src/renderer/src/utils/`、`type/`、`hooks/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `utils/` | 工具函数 | 通用方法、rtc/socket 等前端工具 |
| `type/` | 类型定义 | 组件/业务相关 TS 类型（如 definitionComponent） |
| `hooks/` | 组合式逻辑 | 与代码/配置相关的 hooks（如 `code/config.ts`） |

#### 4.4.10 静态仓库 `src/renderer/staticWarehouse/`

| 路径 | 分类 | 说明 |
|------|------|------|
| `3dModel/` | 静态资源 | 如 GLTF 模型等，供需要时引用 |

## 五、分类归纳表

| 分类维度 | 包含内容 |
|----------|----------|
| **进程** | main（主进程）、preload（预加载）、renderer（渲染进程） |
| **渲染层** | 入口（main/App）、路由、状态、接口、视图、组件、packages、资源、工具与类型 |
| **功能域** | 低代码（物料、渲染、控制面板、表单/表格/容器、代码生成）、对话与 Agent（FloatingChat、设置弹窗）、用户与配置（api、preload 内 user/lowCode） |
| **复用层级** | 全局（FloatingChat、stores、api）、包级（packages）、页面级（views/*/components、hooks、style） |

## 六、快速定位指南

- **改主窗口/启动服务**：`src/main/index.ts`、`src/preload/app/index.ts`  
- **改低代码画布与数据流**：`views/draggingDragging/`、`stores/draggingDragging/`、`packages/RenderEngine/`  
- **改组件库与物料**：`components/materialArea/`  
- **改属性面板**：`packages/ControlPanel/`、`packages/DlockContainer/`、`packages/Form/` 等  
- **改悬浮对话与 Agent 设置**：`components/FloatingChat/`  
- **改接口与持久化**：`api/`、`preload/router/`、`preload/model/`、`preload/service/`  
- **改路由与页面**：`router/`、`views/`  

按上述分类与路径即可快速在项目中定位和扩展功能。
