# 物料平台测试脚本

## 测试物料平台接口是否可用

### 1. 测试登录接口

```bash
# 使用 curl 测试登录
curl -X POST http://127.0.0.1:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"userId":"admin","password":"admin123445"}'
```

预期响应：
```json
{
  "code": 0,
  "result": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

### 2. 测试获取物料列表

```bash
# 先登录获取 token
TOKEN=$(curl -X POST http://127.0.0.1:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"userId":"admin","password":"admin123445"}' \
  -s | grep -o '"token":"[^"]*"' | cut -d'"' -f4)

# 使用 token 获取物料列表
curl -X GET "http://127.0.0.1:3001/api/materials?page=1&pageSize=20" \
  -H "Authorization: $TOKEN"
```

预期响应：
```json
{
  "code": 0,
  "result": {
    "list": [
      {
        "type": "Button",
        "componentName": "按钮",
        "group": "Element",
        "npm": {
          "exportName": "ElButton",
          "package": "element-plus",
          "destructuring": true
        },
        "props": {}
      }
    ],
    "total": 1
  }
}
```

### 3. 测试创建物料

```bash
curl -X POST http://127.0.0.1:3001/api/materials \
  -H "Content-Type: application/json" \
  -H "Authorization: $TOKEN" \
  -d '{
    "type": "CustomButton",
    "componentName": "自定义按钮",
    "group": "自定义组件",
    "icon": "icon-anniu",
    "npm": {
      "exportName": "ElButton",
      "package": "element-plus",
      "destructuring": true
    },
    "props": {
      "type": "primary"
    }
  }'
```

### 4. 测试更新物料

```bash
# 假设物料 ID 为 abc123
curl -X PATCH http://127.0.0.1:3001/api/materials/abc123 \
  -H "Content-Type: application/json" \
  -H "Authorization: $TOKEN" \
  -d '{
    "componentName": "自定义按钮v2"
  }'
```

### 5. 测试删除物料

```bash
curl -X DELETE http://127.0.0.1:3001/api/materials/abc123 \
  -H "Authorization: $TOKEN"
```

## 在浏览器控制台测试

打开应用，按 F12 打开开发者工具，在 Console 中执行：

### 查看当前物料列表

```javascript
import { useMaterialsStore } from '@renderer/stores/materials/useMaterialsStore'
const store = useMaterialsStore()
console.log('物料列表:', store.list)
console.log('加载状态:', store.loading)
console.log('错误信息:', store.error)
```

### 手动登录并拉取

```javascript
const store = useMaterialsStore()
await store.loginAndFetch({ userId: 'admin', password: 'admin123445' })
console.log('拉取结果:', store.list)
```

### 刷新物料列表

```javascript
const store = useMaterialsStore()
await store.refreshList()
console.log('刷新后:', store.list)
```

### 注销

```javascript
const store = useMaterialsStore()
await store.logout()
console.log('已注销，列表已清空')
```

## 常见问题

### 问题 1：连接被拒绝（Connection refused）

**原因**：物料平台服务未启动

**解决**：
1. 检查物料平台是否运行在 `127.0.0.1:3001`
2. 检查端口是否被占用
3. 检查防火墙设置

### 问题 2：401 Unauthorized

**原因**：token 无效或已过期

**解决**：
1. 重新登录获取新 token
2. 检查 Authorization header 格式是否正确
3. 检查后端 JWT 验证逻辑

### 问题 3：404 Not Found

**原因**：接口路径不正确

**解决**：
1. 检查 API 路径是否正确（`/api/auth/login` vs `/login`）
2. 查看后端路由配置
3. 检查物料平台版本是否匹配

### 问题 4：CORS 错误

**原因**：跨域请求被阻止

**解决**：
1. 在物料平台后端配置 CORS
2. 允许来自 Electron 应用的请求（`http://localhost:5173` 或打包后的 `file://` 协议）

## 快速验证脚本

```bash
#!/bin/bash
# 保存为 test-material-platform.sh，执行权限：chmod +x test-material-platform.sh

BASE_URL="http://127.0.0.1:3001"

echo "=== 测试物料平台接口 ==="

# 1. 测试登录
echo "1. 测试登录接口..."
LOGIN_RESPONSE=$(curl -s -X POST $BASE_URL/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"userId":"admin","password":"admin123445"}')
echo "登录响应: $LOGIN_RESPONSE"

TOKEN=$(echo $LOGIN_RESPONSE | grep -o '"token":"[^"]*"' | cut -d'"' -f4)
if [ -z "$TOKEN" ]; then
  echo "❌ 登录失败，未获取到 token"
  exit 1
fi
echo "✅ 登录成功，token: ${TOKEN:0:20}..."

# 2. 测试获取物料列表
echo ""
echo "2. 测试获取物料列表..."
MATERIALS_RESPONSE=$(curl -s -X GET "$BASE_URL/api/materials?page=1&pageSize=20" \
  -H "Authorization: $TOKEN")
echo "物料列表响应: $MATERIALS_RESPONSE"

# 检查是否包含 list 字段
if echo "$MATERIALS_RESPONSE" | grep -q '"list"'; then
  echo "✅ 获取物料列表成功"
else
  echo "❌ 获取物料列表失败"
  exit 1
fi

echo ""
echo "=== 所有测试通过 ==="
```

使用方法：
```bash
./test-material-platform.sh
```
