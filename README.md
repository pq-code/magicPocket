> 已移除：空间展示(3D)、WebRTC、linkSsh，仅保留低代码与对话相关功能。

## 低代码平台 + AI 如何更优秀

在现有「JSON 驱动 + 拖拽 + 配置面板 + 假代码转真函数」的基础上，结合 AI 可以从以下几方面让平台更优秀：

### 1. 自然语言生成页面
- **描述即搭建**：用户用一句话描述需求（如「做一个用户列表，带搜索和分页」），AI 生成对应的 `pageJSON` 树和组件配置，直接渲染到画布。
- **迭代修改**：对画布说「把搜索框移到右上角」「表格加一列状态」，AI 只改相关节点，避免整页重做。

### 2. 智能配置与补全
- **属性推荐**：在右侧面板选组件时，根据组件类型和已有配置，AI 推荐常用属性组合（如 Table 的 `border`、`stripe`）。
- **表单校验/接口映射**：根据字段名或接口文档，自动生成表单项校验规则、或「提交到某接口」的配置，减少手写。

### 3. 「假代码」升级为自然语言逻辑
- 当前是用户在编辑器里写代码片段，用 `new Function` 执行。可改为：
  - **自然语言描述逻辑**：如「当选择部门时，清空并重新拉取人员列表」，AI 生成对应的 JS 代码再注入执行。
  - **安全兜底**：AI 只生成只读、无副作用的表达式或受控的 API 调用，降低 `new Function` 的安全与稳定性风险。

### 4. 代码生成与可读性
- **按场景生成**：不仅生成当前画布对应的 Vue/JSX 片段，还可按「只要表单」「只要表格」「带路由的完整页」等模板生成，并带注释。
- **与现有工程对接**：根据项目技术栈（Vue2/3、Element/Ant 等）生成可直接粘贴的代码，并说明放在哪个文件、如何接入接口。

### 5. 质量与一致性
- **无障碍与规范**：AI 在生成或修改 JSON 时顺带补全 `label`、`aria-*`、语义化结构，提升可访问性。
- **设计规范**：根据团队设计规范（间距、圆角、色板）校验或自动修正组件样式配置，保证视觉一致。

### 6. 学习与沉淀
- **从历史配置学习**：把已保存的 `codeConfig` 作为样本，训练或微调「描述 → JSON」模型，使生成结果更贴近团队习惯。
- **组件用法说明**：在组件库中为每个组件生成「何时用、怎么配、常见坑」的简短说明，由 AI 从文档或代码中抽取。

**落地建议**：优先做「自然语言生成 pageJSON」和「假代码改为自然语言描述逻辑」，这两块最能体现「低代码 + AI」的差异；其余能力可做成可选功能，逐步迭代。
